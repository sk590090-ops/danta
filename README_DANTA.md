# AutoDanta — 바이낸스 선물 단타 자동매매 시스템

검증을 통과한 신호만 실행에 연결하는 1시간봉 단타 봇. 전 코인 거래량 스크리닝 →
전조 탐지 → 자동 진입/청산 → 대시보드·텔레그램 알림까지 단일 파이프라인.

> ⚠️ 교육·연구용. 투자 조언이 아니며 수익을 보장하지 않습니다.
> 실주문은 기본 **테스트넷**이며 실서버 전환에는 명시적 환경변수가 필요합니다.

## 핵심 원칙

**검증되지 않은 아이디어는 실행에 연결하지 않는다.** 이 레포의 모든 셋업은
워크포워드/롤링 OOS를 통과했거나, 통과하지 못해 기각된 기록이 함께 남아 있다.

## 파이프라인 (매시간 자동)

```
전 선물심볼(≈670) 스캔
 ├─ 유니버스: 거래대금 상위 50 → 거래량 Z≥2 → BTC 대비 상대강도
 │   └─ 인버스/변동성 ETF 토큰(SOXS·SQQQ·UVXY 등) 제외
 ├─ [신호] OBV 다이버전스 → 자동 진입          (WFA 통과: 1h PF 1.31)
 ├─ [전조] 6-way 레이더 → 브래킷 설치 → 발동 방향 진입 (PF 1.52)
 ├─ 보유 포지션 정산 (손절 / 목표 2R / 48h 시간청산)
 └─ 대시보드 갱신 + 텔레그램 알림
```

## 검증 요약 (전부 실측)

| 항목 | 결과 |
|---|---|
| OBV_DIV 워크포워드 | 1h: n180 · avgR +0.071 · **PF 1.31** · 흑자폴드 5/8 |
| OBV_PRD(대안 정의) | 1h PF 0.92 → **기각**, 기존 정의 우세 |
| 6-way 전조 lift (13만 샘플) | 점화 1.57 · 펀딩 1.38 / **압축 0.68 · 매집 0.58 = 역예측 → 투표권 박탈** |
| 진입 방향 5규칙 | 방향예측 4종 전패(PF 0.82~0.98) vs **브래킷 PF 1.52** |
| 브래킷 유효시간 2~24h | PF 1.42~1.47 **고원**(파라미터 비민감 = 노이즈 아님) |
| 포트폴리오(슬롯·레버) | 슬롯 3 초과 무의미 · 레버 상한 2x는 "공짜 보험"(수익 손실 0%) |

기각된 것도 그대로 기록: 이평선 수렴(CONVERGENCE), 캔들·차트패턴,
4지표 컨플루언스, VWAP 단독 신호 — 전부 검증에서 탈락.

## 리스크 규칙

- 트레이드당 리스크 **1.5%** (손절 = 1×ATR14, 목표 = 2R)
- 동시 포지션 **3개**, 레버리지 상한 **2배** (실사용 중앙값 0.64x)
- **일손실 −5%** 도달 시 당일 신규 진입 자동 중단
- 손절/익절은 **거래소측 조건부 주문**으로 설치 → 봇이 꺼져도 집행됨

## 사용법

```bash
python tools/daily_scan.py                    # 스캔만 (읽기 전용)
python tools/daily_scan.py --trade            # 페이퍼 원장 자동매매
python tools/daily_scan.py --trade --live     # + 실주문(기본 테스트넷)
python tools/daily_scan.py --selftest         # 로직 자가검증
```

연구 도구:
```bash
python tools/radar_backtest.py --long         # 전조 lift 측정
python tools/radar_entry_study.py             # 진입 규칙 비교
python tools/portfolio_sim.py                 # 슬롯·리스크·레버 시뮬
python tools/bracket_window_sweep.py          # 파라미터 민감도
```

## 실주문 설정

```bash
# 테스트넷 키 (testnet.binancefuture.com)
setx BINANCE_API_KEY "..."
setx BINANCE_API_SECRET "..."
```

실서버 전환은 **의도적으로 번거롭게** 만들어져 있습니다:
`DANTA_LIVE_CONFIRMED=YES` + `DANTA_MAX_NOTIONAL`(주문당 상한) 둘 다 필요.

## 구성

| 파일 | 역할 |
|---|---|
| `tools/daily_scan.py` | 메인 파이프라인 (스캔·신호·레이더·브래킷·원장·대시보드) |
| `tools/binance_live.py` | 실주문 모듈 (HMAC 서명, 거래소측 SL/TP) |
| `ptrader/` | 신호 엔진 (지표·셋업·플래너·리스크·백테스터) |
| `docs/` | 기획서 + 전 검증 기록 |

## 알려진 한계

- 전조 연료·수급 축은 거래소가 OI·테이커 이력을 30일만 제공 → 장기 검증 불가
- 포트폴리오 시뮬은 브래킷 단독, 10개월 단일 경로, 슬리피지 미반영
- 실전 표본이 아직 적음 — 성적은 누적 중
